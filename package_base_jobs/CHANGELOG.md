# 0.5.0 candidate

- Job stat trainings: each job's deep shared Battle/Magick Lores become two licenses of its own (e.g. Hunter
  Fleetfoot I/II: Strength and Speed), with effects from an included The Insurgent's Stat Lores config. Shared basics
  unchanged. Boards: 223 → 171 stat tiles, re-laid out with the same rules, islands and shared tools as 0.4.1.
- Builds over an installed 0.4.1.

# 0.4.1 candidate

- Shared basic tools where another role needs them: Decoy + Oil (Knight, Warrior), Cure + Blindna (Knight), Protect +
  Shell (White Mage), Vox + Poisona (Chemist), Dispel + Stona (Lancer), Charge (Black Mage, Time Mage), Libra
  (Gunner, Green Mage, Mystic), First Aid (Warrior, Samurai, Hunter). Every job gains at least one tool.
- Same legendary islands, names, contents and prices as 0.4.0.

# 0.4.0 candidate

- Every board carries the same thirteen islands: each Esper gates its zodiac weapon, Zodiark gates Masamune. An
  island opens only for a character who owns that Esper (use Summons For All so anyone can license any Esper).
- Mesa, Mina, Tula and Simha now stand alone in their licenses (renamed after them); Yagyu Darkblade, Shikari Nagasa,
  Gastrophetes and Durandal move to Ninja Swords 3, Daggers 6, Crossbows 3 and Swords 8.
- Mithuna and Tula return to their native LP (190, 115); the other six price increases stay.
- Cores keep the compact regions; Quickenings are plain edge tiles.

# 0.3.0 candidate

- Redrew all twelve boards as compact regions: gear up, accessories left, passives right, commands down.
- Cheaper licenses sit nearest Essentials; no long single-tile corridors.
- Espers and Quickenings are edge tiles with one ordinary neighbour; the Second Board stays a leaf.
- Kumbha and all Knight armor now sit in the Knight's gear region.
- Same licenses, LP prices and descriptions as 0.2.0; boards may contain loops like native boards.

# 0.2.0 candidate

- Removed heavy armor from Gunner; limited Chemist to eight Battle Lores.

- Raised eight exclusive weapon-license LP prices; all other table bytes stay unchanged.
- Rewrote all twelve English job descriptions, preserving native prompts.
