Ivalice Legacy - HUD themes folder
==================================

Put player-made HUD themes here, one folder per theme:

    themes\<theme id>\theme.json
    themes\<theme id>\atlas\theme.atlas
    themes\<theme id>\icons\icons.json   (only if theme.json names an icon file)

The folder name must equal the theme's "id" (lower-case letters, digits, "-" and "_").
Choose the theme in game: Mod Menu > Ivalice Legacy > Co-op > HUD > HUD theme.

A theme the game cannot read is not offered, and one line in x64\hook.log says why.
Only use fonts whose licence lets you embed them (the atlas contains their outlines).

Full guide: docs/THEMES-README.md in the Ivalice Legacy repository.
